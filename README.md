# Mukanda App

Aplicação móvel para gestão e rastreamento de entregas em tempo real, desenvolvida como Projecto de Fim de Curso.

## Sobre o projecto

O Mukanda App foi desenvolvido para facilitar a gestão de pedidos e entregas, permitindo a integração entre clientes, estabelecimentos e estafetas.

A aplicação procura melhorar o acompanhamento das entregas através de geolocalização, actualizações de estado e comunicação entre os intervenientes.

## Principais funcionalidades

- Autenticação de utilizadores
- Gestão de pedidos
- Rastreamento de entregas
- Geolocalização
- Integração de mapas
- Actualizações em tempo real
- Notificações
- Histórico de pedidos
- Gestão de perfil
